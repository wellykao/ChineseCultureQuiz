# 内置题库

`questions.json` 是完整 2394 道题的题库，与下载版 EXE 对应。普通用户无需打开本目录，题目已嵌入 EXE。

题型为单选 884、多选 501、判断 500、填空 500、阅读理解 9。题库入口存在交集，不能将入口题量相加。22 题标为已核验，2260 题沿用原资料答案，112 题待复核；默认练习排除待复核题。

第三方题目权利归原权利人，维护者已确认本次公开传播具有相应权限；下载者应遵守相关授权范围。参考答案可能存在错误，不等于官方题库或历年真题。

维护格式时保持题目 ID 稳定，字段与来源见实际 JSON；`evidence` 保存核查链接，`review` 标记待复核，`banks` 为入口归属，原答案和订正说明分别保留。
