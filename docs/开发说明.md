# 开发说明

普通用户从首页下载现成 EXE 即可，不需要本文步骤。

源码使用 C# / .NET Framework WinForms。维护代码时，在 Windows PowerShell 中运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\build.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\test.ps1
```

默认从 `data/questions.json` 嵌入完整 2394 道题，输出 `dist/ChineseCultureQuiz.exe`。自测使用 `test-output/` 下的独立记录，不读取真实学习记录。

`src/` 为程序源码，`scripts/` 为构建与校验脚本。源码、题库与 Release EXE 均为完整版本；旧的 16 题示例入口已撤下。

原始资料中的大文件保存在同一公开仓库的 Release 下载包中；资料包保留全部原分类、24 份原文件和各文件夹 README。源码仓库中的 `资料/` 用于在线查看目录与选读说明。
