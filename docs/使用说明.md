# 使用说明

先运行根目录 README 中的构建命令，再打开 `dist/ChineseCultureQuiz-Demo.exe`。默认题库只有 16 道自编示例题，用于展示程序功能；并非完整考试复习资料。

左侧选择题库、题型、专题、练习方式、答案状态与每轮题量，点“开始 / 应用筛选”。数字键选择选项，回车提交。填空题显示参考答案后需自行判断；不将同义表述直接判错。只有题库包含相应题型时该筛选才会有结果。

错题本可以按错次、状态等筛选，标注错因、手动加入、标为掌握、移出或重新巩固。手动收录和掌握不伪造答题次数。同一天连续答对不会直接算作跨日掌握；本机日期错误可能影响复习安排。

“重置/恢复”提供重练当前轮、重置题目进度、重置全部进度、清空错题本和恢复初始设置。执行前核对界面显示的范围：进度重置通常保留收藏和笔记，恢复初始设置会清除这些内容。大范围操作需输入“重置”。开始重置前会保存独立副本，备份失败则拒绝执行；可用“恢复操作前记录”回退整个学习记录，操作后的新答题也会回退。

示例版记录在 `%LOCALAPPDATA%\ChineseCultureQuizDemo\progress.json`，原完整本地版使用 `%LOCALAPPDATA%\ChineseCultureQuiz\progress.json`。两者不互相读取。记录为明文，包含个人笔记，不应上传 GitHub。软件提供手动备份和恢复、每日备份及损坏恢复；请对重要内容另行保留独立备份。

“恢复初始设置”会保留操作前恢复副本，不能用来彻底擦除历史个人信息。如果确需彻底移除，先关闭程序并确认不再需要恢复，再通过文件管理器自行处理相应记录目录及已导出的备份。

程序日常练习不联网；点击来源链接会调用浏览器访问外部机构页面。来源核查标记不等于官方授权或所有答案永久正确。详见 [免责声明](免责声明.md)。
