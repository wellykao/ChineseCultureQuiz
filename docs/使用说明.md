# 下载后怎么用

1. 在首页点击“下载刷题工具 EXE”。
2. 下载完成后，双击打开它。
3. 选择答案，点“提交答案”，再点“下一题”。

内置 2394 道题，日常练习不需要联网。适用 Windows 10 / 11，无需安装 Python、编译器或开发工具。

答错的题会自动进入“错题本”。可以加收藏、写笔记，也可以从“重置/恢复”选择重新练习或清除进度；执行前请看清界面显示的影响范围。

下载全部资料时，右键 ZIP 选择“全部解压”，打开“先看这里.txt”。各资料文件夹的 README 都说明该看哪些内容。

进度保存在当前电脑。换电脑前点程序里的“备份记录”，在新电脑中用“恢复记录”导入即可。不要把个人记录上传到仓库。
