# 代码保护与授权边界

本项目采用私有仓库和专有权利声明。仓库所有者为 `wellykao`，不采用 MIT、Apache、GPL 等开源许可。仅对实际拥有且依法可保护的部分主张权利。

## 本次措施

- 以私有可见性创建仓库，不邀请额外协作者、不主动开放公开发行物。
- 使用 LICENSE、NOTICE 和源码文件头说明权利及授权范围。
- 提交完整软件源码与题库，在私有发行包中保存原资料；不上传个人学习记录及凭据。
- 保留 Git 版本历史与提交标识，用于定位版本和记录变化。版本记录有助于留存事实，但不是著作权登记，也不能单独证明所有权或原创性。

`.gitignore` 只帮助避免意外加入文件，不是访问控制，也不能阻止强制添加；每次上传仍需检查实际提交清单。

## 能保护什么

私有仓库限制未授权账户直接访问源码；仓库管理员、获授权协作者及按平台条款提供服务所必需的主体仍可能访问。能取得文件的人仍可能复制或截图，已下载副本也无法靠修改仓库权限远程撤回。C# EXE 可以被分析或反编译；本项目未加入 DRM、代码加密或反编译保护。

许可证表达授权边界，不提供“绝对不被抄袭”的技术保证。事实、思想、算法原理、公共领域内容及部分 AI 生成表达可能不具有可由你排他主张的著作权。第三方材料的权利不能通过本声明转移给仓库所有者。

如将来主动改为公开，应先复核第三方权利和个人信息，并理解 GitHub 服务条款允许其他用户通过平台查看及 fork 公开仓库。不得把本声明理解为否定已同意的平台必要权利或法定例外。[GitHub 用户内容条款](https://docs.github.com/en/site-policy/github-terms/github-terms-of-service#d-user-generated-content)

## 后续维护

只向确有需要的人授予最小访问权限；如平台与套餐支持，可限制私有 fork、保护分支和启用双因素认证。分支保护用于降低误改或强推风险，并不防止代码复制。这些账户或套餐级设置需要另行确认，本文不表示已启用。

如发现侵权，保留原始代码、提交记录、发布记录、侵权页面及时间等证据，核实自己的实际权利和对方可能具有的授权或法定使用权，再按平台流程或适用法律处理。[GitHub 版权政策](https://docs.github.com/en/site-policy/content-removal-policies/dmca-takedown-policy)
