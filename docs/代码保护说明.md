# 代码保护与授权边界

本仓库已按维护者要求公开，用于展示项目并提供下载。公开可见不等于开源授权：软件代码和原创表达仍按 LICENSE 保留依法实际享有的权利；发行页 EXE 允许个人非商业学习用途下载和运行。第三方资料权利归原权利人，维护者已确认本次公开传播具有相应权限。

## 已采用的措施

- 使用 LICENSE、NOTICE 与源码文件头说明权利及授权范围。
- 不发布个人做题记录、笔记、备份、账号凭据或密钥。
- 保留版本记录、原资料校验表和发行文件校验值，以便定位变化和核对文件。

GitHub 公开仓库允许其他用户通过平台查看与 fork；这些平台权利不因本项目专有声明而被取消。公开源码和已经下载的副本无法靠许可证或以后改为私有来阻止复制。[GitHub 用户内容条款](https://docs.github.com/en/site-policy/github-terms/github-terms-of-service#d-user-generated-content)

本项目未加入 DRM、代码加密或反编译保护，C# EXE 可以被分析。许可证表达授权边界，无法保证绝对不被抄袭。事实、思想、算法原理、公共领域内容及部分 AI 生成表达可能不具有可由维护者排他主张的著作权。

发现侵权时，应核实实际权利、对方授权与法定使用情形，并保留相关证据，再按平台流程或适用法律处理。版本历史不等于著作权登记，也不能单独证明所有权。[GitHub 版权政策](https://docs.github.com/en/site-policy/content-removal-policies/dmca-takedown-policy)
