## 2024老吕管综 秒杀技总结手册.pdf

**判断：有用，Z001 逻辑辅助。**

- 建议看：PDF 5—85 页（书页 1—84）七个部分：41 个考点、8 类谬误、82 个技巧、形式逻辑易错点、综合推理难点、论证逻辑干扰项、口诀。先读第 1—2 部分基础与谬误，再读第 4—6 部分；第 3、7 部分用于做题后的总结。
- 可跳过/降优先级：封面目录及末页广告跳过；不要依靠“秒杀”口诀代替理解充分必要条件、量词、推理和论证。Z002 不需要读。
- 理由与用途：虽然文件名泛称管综，实际目录与抽查正文都是逻辑，不应误判为数学/写作混合材料。
- 检查依据及限制：扫描件；已核对目录、开头、技巧区、末尾。封面版权为 2022，北京；文件名前缀 2024 不据此认定实际出版年份。
