## 中华文化概要课本.pdf

**判断：有用但只作工具书，按专题查。**

- 建议看：实际为谭家健主编《中国文化史概要（增订二版）》。书内页码：第一编典章制度 3—103 左右（礼制、称谓、官制、兵制、学校、科举、赋役、度量衡、历法）；第二编古代各体文学 105—200 左右；第三编哲学宗教 205—347 左右；第四编重点查文字书法 359 起、美术 371 起、音乐 394 起、园林 410 起、图书 421 起、衣食住行 430 起、四大发明 442 起。
- 可跳过/降优先级：文学批评、骈文格律的细枝末节、思想家的大量生平细节，以及末尾文化史著作书目、后记不必背；体育杂技和“机器人”章节按兴趣或具体考点查。
- 理由与用途：四编与文化常识重合广；适合补艺术、制度、哲学，513 页且为大体积扫描本，通读成本高。
- 检查依据及限制：已看封面版权、完整目录及正文样页。上列均为书内印刷页码，不能直接输入为 PDF 页码；例如书页 3 对应 PDF 14。

## 中华文化概要课本第二版.pdf

**判断：部分有用，思想文学优先。**

- 建议看：实际为陶嘉炜编著《中国文化概要（第二版）》。书页 67—115“思想篇”，119—160 左右“历史篇”，163—213“文学篇”优先；附录“名词解释”214 起作查询。语言篇只查汉字演变、诗歌语言与文化相关基础知识。
- 可跳过/降优先级：绪论文化理论、语言学/语法机制、翻译专业背景、字母词等不作第一轮重点；不用因文件名“第二版”就替代另一部文化史工具书。
- 理由与用途：思想、历史、文学相关；艺术与古代科技覆盖不足，不能当作唯一教材。
- 检查依据及限制：已看封面版权和全部目录。本书源自翻译专业书系，233 个 PDF 页面；书页 1 对应 PDF 16，上列推荐区间按印刷页码查询。
