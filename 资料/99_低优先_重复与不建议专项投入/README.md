## 《公基》《常识》系统课讲义——马克.pdf

**判断：对当前任务新增价值低，重复备查。**

- 建议看：若专题节选缺页或要上下文，只查 PDF 106—134 页第八章“历史人文”（书页 105—133），其中 PDF 134 已衔接下一章；其主体已另存于 01 文件夹的 29 页节选。
- 可跳过/降优先级：无需从头通读 342 页。法律法规、管理、经济、公文、事业单位制度、现代自然科技等均不作为本次文化专项学习内容。
- 理由与用途：不是完全没用，而是相关章已有独立文件；整本重复学习几乎无新增收益。
- 检查依据及限制：已提取全文并比对标题、正文和页码：第八章与独立节选重合，节选多带了前后章的少量内容。

## 高考必考高中必背64篇古诗文理解性默写（word版）.pdf

**判断：投入产出低，不建议专项刷默写。**

- 建议看：仅回查错题涉及的作者作品、名句含义和文章主旨；例如《劝学》等经典可帮助阅读理解，但仍需要读原文、注释和释义。
- 可跳过/降优先级：不要按高考要求逐篇做填空、练字形和整篇默写。Z001/Z002 的文化阅读为理解辨析，不能用默写材料代替阅读训练。
- 理由与用途：不是没有文化内容，而是练习目标偏向高考背诵默写，19 页专项投入不如优先完成框架与选择题。
- 检查依据及限制：已提取全篇文字核对材料性质；未提供系统阅读理解训练。
