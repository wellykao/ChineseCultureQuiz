## 中华文化2000题(可添加注释版).pdf

**判断：部分有用，单选优先且与 Excel 高度重复。**

- 建议看：PDF 27—111 页为单选区（书页 25—109），先做与五类中华文化范围相符的题。PDF 3—26 页填空、112—192 页多选、193—220 页判断按薄弱知识点选做；答案见同目录答案汇总。
- 可跳过/降优先级：不按填空、多选、判断训练正式考试作答方式；不把全部 2000 题当必考清单。
- 理由与用途：有题量，适合查漏；其四类各 500 题与 Excel 内容高度重合，选一个载体即可。
- 检查依据及限制：已读取全文与分区目录。对 Excel 2000 个题干去标点及空白比对，1987 个在本 PDF 中匹配，另外 13 个不据此判不同题（可能为排版或文本差异）。

## 中华文化答案汇总.pdf

**判断：配套有用，但答案须纠错。**

- 建议看：和 2000 题按题型及题号核对；目录标注书页：填空 1—30、单选 31—54、多选 55—73、判断 74—95；本 PDF 共 96 页，封面导致页码存在偏移，遇边界按题型标题与题号找。
- 可跳过/降优先级：不要脱离题目通背全部解析；不把民间题库答案当权威结论。
- 理由与用途：便于错题追因，但抽查发现答案表述问题，需以教材、经典原文核验。
- 检查依据及限制：已提取全文。填空第 17 题（PDF 3—4 页附近）把“第一部编年体史书”答为左氏春秋，须区分《春秋》与“叙事详细”的《左传》；详见 00 文件夹 README 的核查记录。

## 2022年全国港澳台大学生中华文化知识大赛题库.xlsx

**判断：部分有用，PDF 题库的可筛选替代载体。**

- 建议看：四个工作表“填空题、单选题、多选题、判断题”各 500 题；优先单选题工作表，按中国哲学、历史、文学、艺术、古代科技挑题。其他表只用于知识点自测。
- 可跳过/降优先级：不再与 2000 题 PDF 全量重复刷；不因名称含“港澳台”而当作研究生招生真题。
- 理由与用途：适合搜索、筛选、做错题标记。文化知识大赛与研究生考试属于不同用途。
- 检查依据及限制：用电子表格读取流程查看工作表结构和全部题干；2000 个题干中 1987 个可在 PDF 规范化文本中匹配。答案与 PDF 同源风险较高，未逐条校正。

## 常识 考题.pdf

**判断：部分有用，人文练习补充。**

- 建议看：全件 PDF 1—50 页是“第一章 人文常识”，含文化、文学、中国历史及世界历史；优先其中“文化常识”“文学常识”的中国题，以及“中国历史”。每节先做“夯实基础”，再选做“高难进阶”。对照同目录常识答案按节名及题号查解析。
- 可跳过/降优先级：世界历史、外国文学和体育规则题可跳过；特别偏细的地方史料题放后。最后 PDF 49—50 页已经出现世界历史题，按内容筛除。
- 理由与用途：题干和解析配套完整，适合练常识辨析；公务员题材与港澳台考试难度、分布不等同。
- 检查依据及限制：扫描件，已检查开头、各段样页和末页；各小节题号会重置，不能只凭题号跨节找答案。

## 常识 答案.pdf

**判断：配套部分有用。**

- 建议看：PDF 1—121 页中，与“常识 考题”选做的中国文化、文学、中国历史题对应的解析。按“文化常识/文学常识/中国历史 + 夯实基础/高难进阶 + 题号”定位。
- 可跳过/降优先级：跳过对应世界史、外国文学、体育等不选做题的解析；页面中“粉笔大数据”正确率不需背。
- 理由与用途：主要价值是解释错误选项，配合题册使用即可。
- 检查依据及限制：扫描件，已看首部、中文文学、中国史及末段样页；不保证每道解析无误。
